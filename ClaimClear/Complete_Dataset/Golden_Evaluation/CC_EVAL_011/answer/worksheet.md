## 5. Proportionate deduction (Cl. 4.1 Note 2)
- High dependency unit - room rent (treated as ICU): ratio = cap / actual rate = 4/5 = 0.8000
- Private room - days 1 and 2: ratio = cap / actual rate = 10/11 = 0.9091
- Ratio applied = 4/5 (0.8000) - lower of the two ratios, DECISIONS.md item 2.
- Base = all other hospital expenses except medicines (only medicines exempt, DECISIONS.md item 1), excluding non-payable/subsumed items and the ambulance benefit: Rs 94,300.
- Deduction = Rs 94,300 x (1 - 4/5) = Rs 18,860 (rounded half up).

## 6. Admissible amount
