## 5. Proportionate deduction (Cl. 4.1 Note 2)
- Single room - day 1: ratio = cap / actual rate = 5/6 = 0.8333
- Single room - day 2: ratio = cap / actual rate = 5/6 = 0.8333
- Ratio applied = 5/6 (0.8333) - lower of the two ratios, DECISIONS.md item 2.
- Base = all other hospital expenses except medicines (only medicines exempt, DECISIONS.md item 1), excluding non-payable/subsumed items and the ambulance benefit: Rs 74,150.
- Deduction = Rs 74,150 x (1 - 5/6) = Rs 12,358 (rounded half up).

## 6. Admissible amount
